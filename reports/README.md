# JEV Reporting and Cost Tracking

JEV records costs as immutable cost events linked to projects and, when available, tasks.

Reports aggregate:

- work-order states
- completed and blocked work
- approvals and changes requested
- total AI/platform cost
- cost by provider
- project budget and remaining budget

The reporting layer is independent from the dashboard UI so the same data can later be exported to PDF, Excel, API responses or scheduled reports.
